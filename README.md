# Meridian Standard — prototype package

This package contains an original draft operating standard and a static website prototype.

## Files

- `index.html` — website entry point
- `styles.css` / `app.js` — website assets
- `SPECIFICATION.md` — complete draft specification
- `standard-clauses.json` — machine-readable normative clauses
- `regulatory-profiles.json` — reference applicability profiles
- `meridian.schema.json` — starter JSON Schema for a Service Passport
- `example-service-passport.yaml` — example manifest

## Run locally

Open `index.html` directly, or serve the directory with any static HTTP server. For example: `python3 -m http.server 8000`.

## Important

The framework is not legal advice. Regulatory applicability and mappings must be validated against authoritative law and standards by appropriately qualified owners.
